# Muse’s Emporium Logo Assets

Website-ready starter SVG assets.

Files:
- primary_logo.svg: full primary lockup with tagline
- wordmark.svg: simplified horizontal wordmark
- monogram.svg: circular M submark
- favicon.svg: simplified favicon
- palette.css: brand colour variables

Recommended website usage:
- Use primary_logo.svg in hero/header areas.
- Use wordmark.svg in nav bars.
- Use monogram.svg for social profile images, footers, stamps, cards.
- Use favicon.svg as the browser favicon.
- Use palette.css for matching page colours.

Note:
These SVGs use web-safe fallback fonts. For a closer match to the mockup, load:
- Playfair Display
- Cormorant Garamond
